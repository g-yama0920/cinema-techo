# シネマ手帖（Cinema Techo）

映画・ドラマ・アニメの「見た／見たい／視聴中／評価保留」をひとつにまとめる、自分専用の記録アプリです。
デザインは動画配信サービス風のダークテーマ（黒に近い背景・白い文字・鮮やかな赤・ポスターの横スクロール。英字の見出しと数字は Bebas Neue、日本語は Noto Sans JP）。iPhone Safari を最優先に作っています。
既存サービスのロゴや専用書体は使っていません。

- ログイン不要。データは端末のブラウザ内（IndexedDB）に保存
- TMDb の API キーが無くても、登録・評価・閲覧・統計はすべて使える
- PWA 対応（ホーム画面に追加・オフライン起動）

## 使い方（開発）

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 単体・受け入れテスト（Vitest）
npm run build        # 型チェック + 本番ビルド（dist/）
npx vite preview --port 4173 &   # ビルド結果を確認
npm run e2e          # 実画面での受け入れ確認（Playwright / 375px）
```

## 初期データ（全作品）の投入

正式データ `movie_tracker_full_catalog.json` と照合用 `movie_tracker_full_catalog.csv` を使います。

1. **同梱して自動投入（おすすめ）**：2つのファイルを `seed/` に置いてビルドすると、
   データが空の端末で初めて開いたときに全作品が自動で登録されます（既にデータがある端末では何もしません）
   - `seed/*.json`・`seed/*.csv` は `.gitignore` 済み（個人データを誤ってコミットしないため）
   - 公開サーバーに置く場合、同梱したファイルの中身は誰でも取得できる点に注意
2. **アプリから**：設定 →「初期データを取り込む」で JSON（と照合用 CSV）を選ぶ。CSV（schema_version 2 の列構成）だけでも取り込めます。
   件数・平均評価・CSV との照合結果・注意事項・一覧を確認してから取り込めます

実データで作業完了条件（全107・評価済み44・平均3.00・評価保留7・未視聴1・見たい3・未確認52・CSV一致・再取り込みで重複なし）を確認：

```bash
cp movie_tracker_full_catalog.json movie_tracker_full_catalog.csv seed/
npm run verify:seed
```

### 分類

| 表示 | 意味 | 視聴済みに数える |
|---|---|---|
| 視聴済み（★あり） | 評価済み | ○ |
| 評価保留 | 見たが評価はまだ（星なし） | ○ |
| 未視聴 | 見ていない | × |
| 見たい | 見たいリストに固定番号付きで登録（作品番号とは別） | × |
| 未確認 | 見たかどうか分からない | × |
| 確認待ち | 状態ではなく目印。同名作品・漫画と映像化作品の区別などが曖昧で、利用者の判断が必要 | — |

### 取り込みのルール

- 元データに明示された状態・評価をそのまま使う（評価は整数1〜5以外を取り込まず「確認待ち」にして値をメモに退避）
- 状態も評価も無い行は「未確認」。見ていない状態なのに評価がある行は評価として数えず「確認待ち」
- 視聴日は「視聴日」を表す項目からだけ読む。登録日・更新日は視聴日にしない。無ければ `null`
- 冪等：作品番号が既にある記録は追加しない。**既存データは削除・上書きしない**。
  内容が違う作品はプレビューに差分として表示し、利用者がチェックを入れたときだけ更新（感想・タグ・視聴記録は残す）。
  タイトルが違う番号は別作品の可能性があるため自動では更新しない
- 作品番号はそのまま管理番号に使い、新しい作品は最大番号の次から。削除しても番号は再利用しない
- 以前の個別ルール（No.31 の別題、No.38 未視聴、No.47 版未特定、三体＝中国ドラマ版）は、元データに明示が無いときだけ補う
- キー名は英語・日本語・表記ゆれをある程度吸収します（`work_no/no/作品番号`, `title/タイトル`, `rating/my_rating/評価`, `status/状態`, `watchlist_no/見たい番号`, `needs_review/確認待ち` など）。
  読めない形式のときはプレビューにエラーが出て、取り込みは行いません

### 作品情報の取得（TMDb）

設定 →「作品情報の一括取得」で、未取得の作品のポスター・公開年・ジャンル・あらすじなどを取得します。
タイトル・区分・公開年が一致する候補が1件だけの作品だけ自動で紐付け、空欄だけを埋めます（タイトル・評価は変えません）。
同名の候補が複数ある・区分が合わない作品は「確認待ち」にして、詳細画面の「編集 → TMDb で探して紐付ける」から選びます。
「確認待ち」「その他（漫画など）」の作品は対象外です。

## TMDb（作品検索・ポスター・配信情報）

API キーはブラウザに埋め込まず、サーバーレス関数（`/api/tmdb`）から使います。

| 公開先 | 置き場所 | 設定 |
|---|---|---|
| 開発サーバー | `server/vite-tmdb-plugin.ts` | `.env.local` に `TMDB_READ_ACCESS_TOKEN=...` |
| Vercel | `api/tmdb/[...path].ts` | 環境変数 `TMDB_READ_ACCESS_TOKEN` |
| Cloudflare Pages | `functions/api/tmdb/[[path]].ts` | 環境変数 `TMDB_READ_ACCESS_TOKEN` |

- プロキシは許可したパス（検索・作品詳細・配信情報など）の GET だけを中継します
- サーバーを用意しない場合は、設定画面で「個人トークン」を選び、この端末だけにトークンを保存できます（バックアップには含まれません）
- 出典表記：TMDb の公式ロゴを `public/brand/tmdb-logo.svg` に置いてください
  （<https://www.themoviedb.org/about/logos-attribution> から入手。開発環境から取得できなかったため未同梱。無い場合は文字表記で表示）
- 配信サービスの情報は JustWatch のデータ（TMDb 経由）で、画面に出典を表示しています

## バックアップ

設定画面から JSON で書き出し・読み込みできます。読み込み前にプレビューが出て、
「追加・更新」または「すべて置き換え」（確認あり）を選べます。CSV（作品一覧・視聴記録）も書き出せます。
ブラウザのデータを消すと記録も消えるため、14日以上バックアップしていないと HOME に案内が出ます。

## 構成

```
src/
  domain/      型・評価ラベル・日付（年/月/日の精度）・統計・カレンダー・初期データ変換（純粋関数）
  data/        リポジトリ（LibraryRepository）と IndexedDB 実装（Dexie）。UI はインターフェースだけに依存
  services/    初期データ取り込み計画・バックアップ・CSV・TMDb クライアント
  ui/          デザインシステム（星評価・ポスター・タブ・シート・トースト など）
  features/    画面（home / works / detail / add / calendar / watchlist / stats / settings）
server/        TMDb プロキシ本体（Web 標準の Request/Response）
api/, functions/  Vercel / Cloudflare 用の薄いアダプタ
tests/         受け入れテスト・変換テスト・TMDb テスト（架空データ tests/fixtures/sample_seed.json）
scripts/       e2e.mjs（画面操作での確認）、make-icons.mjs、make-fixture.mjs
```

クラウド同期を追加するときは `LibraryRepository` を実装したクラス（例：Supabase）を作り、`src/data/index.ts` で差し替えます。

### データモデル

| テーブル | 内容 |
|---|---|
| works | 作品（固定管理番号 catalogNo・元番号 legacyId・別題・版・区分・TMDb ID など） |
| userWorks | 自分の状態・評価・感想・タグ・元の見たい番号 |
| watchEvents | 視聴イベント（再視聴は行を追加。日付は精度付き、不明は null） |
| watchlist | 見たいリスト（固定番号・並び順・視聴予定日・公開予定日・見られるサービス・履歴） |
| ratingHistory | 評価の変更履歴 |
| meta | 番号カウンタ・設定 |

## テスト用データについて

`tests/fixtures/sample_full_catalog.(json|csv)` は **架空の作品名** で今回の構成
（全107＝評価済み44（平均3.00）・評価保留7・未視聴1・見たい3・未確認52、同名作品・漫画の曖昧ケースを含む）を再現したものです。
`tests/fixtures/sample_seed.json` は初回依頼の構成（No.1〜50＋見たい3）です。どちらも実際の評価データではありません。
